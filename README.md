# تم تغيير وجهتك! — نادي العدالة النيابي

## التجربة محليًا
فك الضغط وافتح `index.html` في المتصفح (لا يحتاج إنترنت ولا خادمًا).

## الرفع والنشر على GitHub Pages
1. في github.com اضغط **New repository**، سمّه مثلًا `change-destination` واجعله **Public**.
2. اضغط **uploading an existing file** وارفع **محتويات** المجلد (index.html، style.css، script.js، مجلد assets) ثم **Commit changes**.
3. من **Settings ← Pages**: Source = **Deploy from a branch**، الفرع **main**، المجلد **/(root)** ثم **Save**.
4. بعد دقائق يظهر الرابط: `https://اسم-حسابك.github.io/change-destination/`

## التعديل
أعلى `script.js` يوجد `CONFIG`: موعد الفتح، وعنوان ونص الوجهة (ضع الإعلان الرسمي في `destinationBody`)، ونص تعريف البطولة.
